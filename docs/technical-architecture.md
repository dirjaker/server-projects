# 技术架构文档

## 🏗️ 系统架构概述

本项目采用**前后端分离**的微服务架构，所有项目运行在 Ubuntu 22.04 服务器上，通过 Nginx 统一反向代理。

## 🔧 项目架构模式

### 1. FastAPI + tkinter 双界面模式

大多数 AI Agent 基础设施项目采用此模式：

```
project/
├── src/
│   ├── api/            # FastAPI 后端
│   │   ├── routes/     # API 路由
│   │   ├── models/     # 数据模型
│   │   └── services/   # 业务逻辑
│   ├── gui/            # tkinter 桌面 GUI
│   │   ├── views/      # 界面视图
│   │   ├── widgets/    # 自定义组件
│   │   └── utils/      # 工具函数
│   └── core/           # 核心逻辑
│       ├── engine/     # 核心引擎
│       └── utils/      # 通用工具
├── tests/              # 测试代码
├── docs/               # 文档
├── requirements.txt    # Python 依赖
└── README.md           # 项目说明
```

**架构优势**:
- Web 界面：远程访问、多人协作
- 桌面 GUI：本地操作、快速响应
- 代码复用：核心逻辑共享

### 2. Vue3 + FastAPI 前后端分离模式

Web 应用项目采用此模式：

```
project/
├── frontend/           # Vue3 前端
│   ├── src/
│   │   ├── components/ # Vue 组件
│   │   ├── views/      # 页面视图
│   │   ├── stores/     # 状态管理
│   │   └── api/        # API 调用
│   ├── public/         # 静态资源
│   └── package.json    # 前端依赖
├── backend/            # FastAPI 后端
│   ├── app/
│   │   ├── api/        # API 路由
│   │   ├── models/     # 数据模型
│   │   └── services/   # 业务逻辑
│   └── requirements.txt
└── docker-compose.yml  # 容器编排
```

**架构优势**:
- 前后端独立开发部署
- 清晰的关注点分离
- 易于扩展和维护

### 3. VitePress 文档站点模式

技术文档项目采用此模式：

```
project/
├── docs/               # 文档源文件
│   ├── .vitepress/     # VitePress 配置
│   │   ├── config.mts  # 站点配置
│   │   └── theme/      # 主题定制
│   ├── guide/          # 指南文档
│   ├── api/            # API 文档
│   └── index.md        # 首页
├── .github/            # GitHub Actions
│   └── workflows/      # CI/CD 配置
├── package.json        # Node.js 依赖
└── README.md           # 项目说明
```

**架构优势**:
- Markdown 驱动
- 自动部署到 GitHub Pages
- 本地搜索支持
- 响应式设计

## 📊 数据流架构

### 1. API 请求流程

```
客户端请求
    │
    ▼
Nginx 反向代理
    │
    ▼
FastAPI 路由
    │
    ▼
请求验证（Pydantic）
    │
    ▼
业务逻辑层
    │
    ▼
数据访问层（SQLAlchemy）
    │
    ▼
SQLite 数据库
    │
    ▼
响应序列化
    │
    ▼
返回 JSON 响应
```

### 2. 实时通信流程

```
客户端 WebSocket 连接
    │
    ▼
FastAPI WebSocket 端点
    │
    ▼
消息处理逻辑
    │
    ▼
广播到其他客户端
    │
    ▼
更新 UI 状态
```

### 3. 异步任务流程

```
用户提交任务请求
    │
    ▼
FastAPI 接收请求
    │
    ▼
创建 Celery 任务
    │
    ▼
任务队列（Redis）
    │
    ▼
Celery Worker 执行
    │
    ▼
更新任务状态
    │
    ▼
WebSocket 通知客户端
```

## 🔐 安全架构

### 1. 认证与授权

- **JWT Token**: 无状态认证
- **Session Cookie**: 有状态认证（Web 应用）
- **API Key**: 服务间认证

### 2. 数据安全

- **HTTPS**: 传输层加密
- **SQL 参数化**: 防止 SQL 注入
- **XSS 防护**: 输出编码和 CSP
- **CSRF 防护**: Token 验证

### 3. 网络安全

- **内网隔离**: 服务器位于内网
- **frpc 穿透**: 安全的远程访问
- **防火墙**: 端口访问控制
