## 🚀 快速开始

```bash
# 克隆项目
git clone https://github.com/dirjaker/server-projects.git
cd server-projects

# 创建虚拟环境
conda create -n server-projects python=3.12 -y
conda activate server-projects

# 安装依赖
pip install -r requirements.txt

# 运行项目
python main.py
```
